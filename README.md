# Final Year Project - Steganography Web App

## About the Project
This is a Flask-based web application that lets users hide and retrieve secret messages inside images using steganography techniques. The idea is to make secure communication using images in a simple and user-friendly way.

## What it can do
- Hide secret messages inside images
- Extract hidden messages from images
- Process images securely using Python

## Tech Stack Used
- Python  
- Flask (for backend)  
- OpenCV (for image processing)  
- HTML & CSS (for frontend)

## How to Run This Project

Follow these steps to set up and run the project locally:

1. Install all required dependencies  
2. Create and activate virtual environment:
   ```bash
   python -m venv myenv
   myenv\Scripts\activate
   pip install -r requirements.txt

   python run.py
