Help & Documentation

Quick Start Guide

1. Upload

Click "Upload" and select an image file or drag & drop

2. Choose Scan

Select Quick, Standard, or Deep scan type

3. Analyze

Click "Analyze Image" and wait for results

4. Review

View detailed results and confidence score

Understanding Results

Verdict Levels
CRITICAL

High probability of steganography detected.
Multiple strong indicators suggest hidden data is present. Immediate investigation recommended.

HIGH

Likely steganography detected.
Several suspicious patterns found. Further analysis recommended.

MEDIUM

Suspicious patterns detected.
Some indicators present but not conclusive. May warrant closer inspection.

LOW

Minimal indicators found.
Few weak indicators, possibly false positives. Likely clean.

CLEAN

No steganography detected.
Image appears clean with no suspicious patterns.

Confidence Score

The confidence score (0-100%) indicates how certain the system is about the verdict. Higher scores mean stronger evidence. The score is calculated by combining results from all detection methods with weighted importance.

Scan Types

Scan Type Duration Tests Performed Best For
Quick ~2-5 seconds LSB, Chi-Square, Entropy, Quick Extraction Initial screening, large batches
Standard ⭐ ~5-15 seconds All statistical tests, visual analysis, full extraction Most cases (recommended)
Deep ~15-45 seconds All tests + multi-bit extraction + comprehensive analysis Thorough investigation, forensics

Detection Methods

LSB Distribution Analysis

Examines the distribution of least significant bits. Steganography often produces a near-perfect 50/50 distribution, which is statistically unusual in natural images.

Chi-Square Test

Statistical test that detects unusual patterns in pixel value distributions, particularly in Pairs of Values (PoV) that differ by 1.

RS Analysis

Regular-Singular analysis examines how pixel correlations change when LSBs are flipped. One of the most reliable LSB detection methods.

Sample Pair Analysis (SPA)

Advanced statistical method that analyzes sample pairs to estimate the embedding rate. More sensitive than chi-square testing.

Entropy Analysis

Measures information density using Shannon entropy. High entropy in LSB planes can indicate hidden data.

Data Extraction

Attempts to extract hidden messages using common LSB steganography methods across different color channels and bit depths.

Batch Processing

How to Use Batch Processing
  1. Navigate to "Batch Upload" from the main menu
  2. Select multiple image files (up to 100)
  3. Choose your preferred scan type
  4. Click "Process Batch"
  5. Wait for all images to be analyzed
  6. View results in a summary table
Tips
  • Use Quick scan for large batches to save time
  • Maximum file size: 50MB per image
  • Estimated time: number of images × scan time
  • All results are saved to your history

Frequently Asked Questions

Q: What file formats are supported?

A: PNG, JPEG, JPG, BMP, GIF, and TIFF files are supported.

Q: What's the maximum file size?

A: The default maximum is 50MB per image.

Q: How accurate is the detection?

A: The system achieves >85% accuracy for common LSB steganography methods. Deep scan provides the most accurate results.

Q: Can it detect encrypted messages?

A: The tool can detect that data is hidden but cannot decrypt encrypted payloads. It will show low readability scores for encrypted content.

Q: How long are analyses stored?

A: By default, analyses are stored indefinitely. You can manually delete them or use the cleanup command to remove old files.

Q: Is my data secure?

A: All processing happens locally on your server. No data is sent to external services.

Troubleshooting

Upload fails or returns error
  • Check that file size is under 50MB
  • Ensure file format is supported
  • Try a different image format
Analysis takes too long
  • Try using Quick scan instead of Deep scan
  • Check server resources and CPU usage
  • Reduce image size if very large
False positives
  • Some natural images may trigger detection
  • Use Deep scan for more accurate results
  • Check extraction results - false positives rarely have readable extracted data
